# Practice-area image prompts

Generation mode: built-in `image_gen.imagegen`, one independent call per asset.
Use case: `photorealistic-natural`. These are generated illustrative scenes, not actual firm premises, personnel or documented client matters.
Original output: 1536 × 1024 PNG. Project optimization: resize only to 1200 × 800 and encode WebP, quality 82, using Pillow.

## Shared prompt

```text
Use case: photorealistic-natural. Asset type: premium Qatar law-firm website practice-area card illustration, landscape 1536x1024. Editorial photography, natural fine textures, premium warm amber highlights and dark forest-green accents, walnut wood, brass details. Real photographic perspective, restrained composition, refined warm side lighting. Subject occupies upper and middle two thirds; bottom third may be overlaid by dark webpage gradient and title. No text, no logo, no watermark, no symbols floating in air, no collage, no borders. This is generic illustrative photography, not an actual firm office or actual firm staff.
```
