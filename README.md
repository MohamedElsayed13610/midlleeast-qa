# Middle East & Partners Law Firm

A bilingual Arabic/English law-firm website and consultation platform built for **Middle East & Partners for Law and Arbitration**.

## Overview

The project combines a professional public website with an internal administration area and an online consultation workflow.

## Main Features

- Arabic and English website experience
- Responsive layouts for desktop, tablet and mobile
- Law-firm profile, services, team and contact pages
- Admin area for managing website content
- Online consultation booking flow
- Consultation file upload and protected file access
- Appointment validation and scheduling rules
- Consultation status management
- Lawyer assignment workflow
- WhatsApp-based communication flow for lawyers and clients
- SEO-focused public pages and metadata
- Supabase integration for application data and storage

## Tech Stack

- Next.js / React
- TypeScript
- Supabase
- Drizzle ORM
- Zod
- React Hook Form
- Tailwind CSS
- Modern responsive RTL/LTR UI

## Live Website

https://midlleeast-qa.vercel.app/

## Project Structure

- `app/` — public pages, consultation flow and admin routes
- `components/` — reusable interface components
- `db/` and `drizzle/` — data layer and schema/migrations
- `docs/` — project documentation

## Notes

This repository contains the application code for the law-firm website and its management/consultation features. Environment-specific secrets are not stored in the repository.
